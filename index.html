03 · LEARN

How to balance equations

1

Write the formulas

Make sure every reactant and product has the correct chemical formula. Never change subscripts to balance an equation.

2

Count atoms

Count each element on both sides. Start with an element that appears in only one formula on each side.

3

Add coefficients

Place whole-number coefficients in front of formulas. A coefficient multiplies every atom in that formula.

4

Check & simplify

Recount every element. If all counts match, reduce the coefficients to the smallest whole-number ratio.

Remember: You can change coefficients, but never change subscripts. Changing H₂O into H₂O₂ creates a different substance.
