04 · CHECKER

Check your equation.

Enter a chemical equation and check whether it is balanced. The Checker compares the atom count of every element on both sides and explains any imbalance.

What gets checked?
✓ Same elements on both sides
✓ Same number of atoms for every element
✓ Valid chemical formulas
✓ Simplest whole-number coefficients
Try an example

Choose an equation to place it in the checking box, then check its balance.

Need help?

Open the Balancer to calculate the correct coefficients, or use the learning guide to see the balancing method.
