01 · WHAT IS A CHEMICAL EQUATION?

Describe what happens in a reaction

A chemical equation is a short way of showing a chemical reaction. The substances you start with are called reactants, and the substances formed are called products. An arrow shows the direction from reactants to products.

For example, hydrogen reacts with oxygen to form water:

H₂ + O₂ → H₂O

The equation tells us which substances participate in the reaction, but it is not balanced yet. A balanced equation must contain the same number of atoms of every element on both sides.

Quick practice

In H₂ + O₂ → H₂O, which side contains the products?

The right side.

Key idea

Read an equation from left to right: reactants → products.

Practice

  1. What does the arrow in a chemical equation represent?
  2. What are the substances on the left side called?
  3. What are the substances on the right side called?
02 · READING CHEMICAL FORMULAS

Understand subscripts

A chemical formula tells you which elements are present and how many atoms of each element are in one particle of the substance. A small number written after an element is a subscript.

H₂O

H₂O contains 2 hydrogen atoms and 1 oxygen atom. When there is no subscript, the number is 1.

Parentheses can describe a repeated group. In Ca(OH)₂, the subscript 2 applies to both O and H, so the formula contains 1 Ca, 2 O and 2 H atoms.

Ca(OH)₂ → 1 Ca + 2 O + 2 H

Do not confuse a subscript with a coefficient. A coefficient multiplies the entire formula:

3H₂O → 6 H + 3 O

Common mistake

Never change a subscript to balance an equation. Changing H₂O to H₂O₂ creates a different substance. Balancing is done with coefficients.

Practice

  1. How many oxygen atoms are in Ca(OH)₂?
  2. How many hydrogen atoms are in 3H₂O?
  3. What is the difference between a coefficient and a subscript?
  4. Why should a subscript not be changed while balancing?
03 · CONSERVATION OF MASS

Atoms are rearranged, not created or destroyed

In an ordinary chemical reaction, atoms are rearranged into new combinations. The atoms themselves do not disappear or appear from nowhere. Therefore, every element must have the same total number of atoms before and after the reaction.

2H₂ + O₂ → 2H₂O

Count hydrogen: the left side has 4 H atoms and the right side has 4 H atoms. Count oxygen: the left side has 2 O atoms and the right side has 2 O atoms. The equation is balanced.

This is the central rule behind equation balancing: same number of each type of atom on both sides.

Why coefficients work

A coefficient tells you how many particles or formula units are present. It multiplies every atom in the formula without changing the substance itself.

Practice

  1. Why must the number of each element be equal on both sides?
  2. How many H atoms are in 2H₂?
  3. How many O atoms are in 2H₂O?
  4. Is H₂ + O₂ → H₂O balanced? Explain by counting atoms.
04 · COEFFICIENTS AND SIMPLE BALANCING

Balance equations without changing formulas

Start by writing the correct chemical formulas. Then count each element on both sides. Add coefficients in front of formulas until the counts match.

H₂ + O₂ → H₂O

There are 2 oxygen atoms on the left but only 1 on the right, so put 2 in front of H₂O:

H₂ + O₂ → 2H₂O

Now there are 4 hydrogen atoms on the right, so put 2 in front of H₂:

2H₂ + O₂ → 2H₂O

Now both elements match. Finally, check that the coefficients are in the smallest whole-number ratio.

A reliable routine

1. Write the formulas correctly. 2. Count atoms. 3. Add coefficients. 4. Recount every element. 5. Reduce coefficients if they have a common factor.

Practice

  1. Balance Fe + O₂ → Fe₂O₃.
  2. Balance H₂ + Cl₂ → HCl.
  3. Balance N₂ + H₂ → NH₃.
  4. After balancing, why should coefficients be reduced to the smallest whole-number ratio?
05 · DIATOMIC ELEMENTS

Know the elements that occur as pairs

When these seven elements appear as free elemental substances, they normally occur as diatomic molecules: hydrogen H₂, nitrogen N₂, oxygen O₂, fluorine F₂, chlorine Cl₂, bromine Br₂ and iodine I₂.

H₂ · N₂ · O₂ · F₂ · Cl₂ · Br₂ · I₂

This matters because an element such as oxygen written as O₂ contains two oxygen atoms. Writing O instead of O₂ when oxygen is an elemental reactant changes the chemical equation.

Memory aid

H, N, O, F, Cl, Br, I are the seven common diatomic elements.

Practice

  1. Which formula represents elemental oxygen?
  2. Which formula represents elemental chlorine?
  3. Why does O₂ contain two oxygen atoms?
  4. Balance H₂ + O₂ → H₂O.
  5. Balance N₂ + H₂ → NH₃.
06 · PUTTING IT ALL TOGETHER

Your first complete balancing checklist

Before balancing, check the formulas and element symbols. Remember that capitalization matters: Co is cobalt, while CO is carbon monoxide. Then count atoms, use coefficients, and check your final result.

Final checklist

✓ Correct element symbols
✓ Correct subscripts
✓ Correct diatomic formulas when applicable
✓ Same number of every element on both sides
✓ Coefficients are whole numbers
✓ Coefficients are in the simplest ratio

Once you can reliably do these steps, you are ready for the Intermediate lessons on polyatomic ions, parentheses, fractions and more complicated reactions.
