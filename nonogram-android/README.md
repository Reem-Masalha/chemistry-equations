# Nonogram Puzzle Maker Android app

This app turns a selected photo into a nonogram using grid dimensions that are multiples of 5. It includes image-to-grid conversion, clue generation, a no-guess logical-solvability gate, black-and-white or colored rendering, hints, X marks, error alerts, solution visibility, ratings, curated safe built-in examples, and PDF export.

The current APK intentionally keeps public/private sharing local to the device. A real public community backend requires a server/database and authenticated storage/moderation service; no third-party credentials are embedded in the APK.
