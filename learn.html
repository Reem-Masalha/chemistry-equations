Conservation of mass

Atoms are rearranged during a reaction, not created or destroyed.

THE CORE METHOD

Four steps

1

Write the formulas

Make sure every reactant and product has the correct chemical formula. Never change subscripts to balance an equation.

2

Count atoms

Count each element on both sides. Start with an element that appears in only one formula on each side.

3

Add coefficients

Place whole-number coefficients in front of formulas. A coefficient multiplies every atom in that formula.

4

Check & simplify

Recount every element and reduce the coefficients to the smallest whole-number ratio.

WORKED EXAMPLE

H₂ + O₂ → H₂O

H₂ + O₂ → H₂O
1
Count hydrogen.
There are 2 H atoms on each side.
2
Count oxygen.
There are 2 O atoms on the left but only 1 on the right.
3
Add 2 before H₂O.
Oxygen is balanced, but there are now 4 H atoms on the right.
4
Add 2 before H₂.
Both elements now match.
2H₂ + O₂ → 2H₂O
IMPORTANT RULES

Coefficients, not subscripts

✓ Change coefficients

Coefficients change how many molecules or formula units participate.

2H₂O

✕ Never change subscripts

Changing a subscript changes the substance itself. H₂O and H₂O₂ are different compounds.

H₂O ≠ H₂O₂
