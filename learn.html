Conservation of mass

Atoms are rearranged during a reaction, not created or destroyed.

THE CORE METHOD

Four steps

1

Write the formulas

Make sure every formula is correct. Never change subscripts to balance an equation.

2

Count atoms

Count each element on both sides and find what is different.

3

Add coefficients

Place whole-number coefficients before formulas to change their quantities.

4

Check & simplify

Recount every element and reduce to the smallest whole-number ratio.

WORKED EXAMPLE

H₂ + O₂ → H₂O

H₂ + O₂ → H₂O
1
Count hydrogen.
There are 2 H atoms on each side.
2
Count oxygen.
There are 2 O atoms on the left but 1 on the right.
3
Add 2 before H₂O.
Now oxygen is balanced, but hydrogen has 4 atoms on the right.
4
Add 2 before H₂.
Both elements now match.
2H₂ + O₂ → 2H₂O
