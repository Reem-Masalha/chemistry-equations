Conservation of mass

Atoms are rearranged during a chemical reaction, not created or destroyed.

THE CORE METHOD

Four steps

1

Write the formulas

Make sure every reactant and product has the correct chemical formula. Never change subscripts to balance an equation.

2

Count atoms

Count each element on both sides. Start with an element that appears in only one formula on each side.

3

Add coefficients

Place whole-number coefficients in front of formulas. A coefficient multiplies every atom in that formula.

4

Check & simplify

Recount every element. When all counts match, reduce the coefficients to the smallest whole-number ratio.

WORKED EXAMPLE

H₂ + O₂ → H₂O

H₂ + O₂ → H₂O
1
Count hydrogen.
There are 2 H atoms on each side, so hydrogen is already balanced.
2
Count oxygen.
There are 2 O atoms on the left but only 1 on the right.
3
Add a coefficient of 2 to H₂O.
Now the right side has 2 O atoms, but it also has 4 H atoms.
4
Add a coefficient of 2 to H₂.
Both elements now match: 4 H atoms and 2 O atoms on each side.
2H₂ + O₂ → 2H₂O
IMPORTANT RULES

What not to change

✓ Change coefficients

Coefficients tell you how many molecules or formula units participate in the reaction.

2H₂O

✕ Never change subscripts

Changing a subscript changes the substance itself. H₂O and H₂O₂ are different compounds.

H₂O ≠ H₂O₂
Tip: If a polyatomic ion stays together unchanged on both sides, you can sometimes treat the entire ion as one unit while balancing.
COMMON MISTAKES

Quick checklist

✓ Check that every chemical formula is correct before balancing.
✓ Count atoms again after every coefficient change.
✓ Use the smallest whole-number coefficients at the end.
✓ Do not change subscripts.
✓ If a coefficient is 1, it is normally omitted.
